# متن افشای همکاری در فروش برای Chrome Web Store

این متن در ابتدای توضیحات کامل افزونه و پیش از جزئیات قابلیت‌ها قرار بگیرد تا کاربر قبل از نصب آن را ببیند:

> **شفافیت همکاری در فروش:** PIQO برای بازکردن برخی نتایج خرید از لینک‌های همکاری در فروش استفاده می‌کند. اگر از طریق این لینک‌ها خرید کنید، ممکن است PIQO از فروشگاه کمیسیون دریافت کند.

این متن باید با اعلام نمایش‌داده‌شده در صفحه Onboarding هماهنگ بماند. نام شبکه یا سرویس افیلیت لازم نیست نمایش داده شود؛ اصل همکاری در فروش و احتمال دریافت کمیسیون باید واضح باشد.
