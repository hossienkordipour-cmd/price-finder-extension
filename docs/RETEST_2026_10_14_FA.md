# بازتست اصلاحات پیکو — ۱۴ اکتبر ۲۰۲۶

هدف جلسه: بررسی استخراج، تطبیق و پنل پیکو با تست‌های ثابت و صفحات مرجع در Chrome برای تشخیص اصلاحات موفق، موارد باقی‌مانده و محدودیت پوشش. خرید، ورود، تغییر تنظیمات، انتشار و R08 خارج از محدوده‌اند.
محیط: Windows، Node.js 24.19.0؛ برنچ `codex/digikala-base-price` با HEAD `7e05cdcca51a3f8d8f5554b7088c5dd696009fac` و تغییرات محلی. نسخه نصب‌شده Chrome با شناسه `gkoaddbniajdnjbfommfefpchalcmmpa` مشاهده شد؛ نسخه عددی/مسیر نصب از صفحه داخلی افزونه قابل تأیید نبود.

`npm test`، `npm run test:digikala-all-sources`، `npm run test:base-price`، `npm run test:merchant-price`، `npm run test:technolife`، `npm run test:air-fryer`، `npm run test:divar-product`، `npm run test:divar-image`، `npm run test:sheypoor-price`، `npm run test:etkala`، `npm run test:r04` و `npm run test:r07`.

این‌ها کنترل‌های ثابت/شبیه‌سازی و اجرای کد فعلی‌اند، نه اثبات تطابق تمام نتایج زنده. قیمت انتخاب‌شده و نامعلوم، تبدیل ریال، حفظ لینک افیلیو، فیلتر مدل و ظرفیت، تصویر تأخیری دیوار، عنوان و قیمت شیپور، تشخیص ات‌کالا، کارت بدون توضیحات و هدر/ضربدر کنترل شدند.

## کنترل زنده

- ات‌کالا `/products/324858/…`: عنوان «کیسه فریزر رولی پرفراژ ۱۵۰ عددی لندی»، قیمت فروش صفحه ۱۵۷٬۵۰۰ تومان، تصویر محصول و دکمه پیکو مشاهده شدند. قیمت کارت و کل نتایج پنل از ابزار قابل مشاهده نبودند.
- دیجی‌کالا `/product/dkp-11801878/`: عنوان R50i A3949 و دکمه پیکو مشاهده شدند؛ بخش قیمت خرید اصلی ۲٬۸۸۶٬۷۰۰ تومان برای variant `69617261` داشت. این عدد قیمت صفحه است، نه قیمت کارتِ تأییدشده در این بازتست.
- دیجی‌کالا `/product/dkp-15948785/`: عنوان NA230 و دکمه پیکو مشاهده شدند؛ قیمت خرید اصلی ۲۴٬۶۰۰٬۰۰۰ تومان برای variant `81982707` بود. قیمت کارت در این جلسه قابل مقایسه نبود.
- ات‌کالا `/search/category/1596`: صفحه دسته‌بندی، بدون گالری جزئیات و بدون دکمه پیکو؛ کنترل غیرمحصول موفق بود.

## مورد باقی‌مانده: R06 تعداد برگ

بازسازی مستقیم در تابع واقعی:

```js
assessProductMatch('کیسه فریزر رولی پرفراژ ۱۵۰ عددی لندی', 'کیسه فریزر شیت ۱۰۰ برگی لندی');
assessProductMatch('کیسه فریزر رولی پرفراژ ۱۵۰ عددی لندی', 'کیسه فریزر رولی ۳۰۰ برگ لندی');
```

هر دو `accepted: true, score: 0.8, confidence: medium, reasons: []` برگرداندند؛ انتظار رد تعداد صریح متفاوت است. عناوین مقصد در این بازسازی داده ثابت تست‌اند، نه ادعای وجودشان در نتایج زنده همین لحظه. عبارت‌های «برگ/برگی» در عنوان‌های واقعی دسته‌بندی ات‌کالا هم مشاهده شدند، اما وجود آن کارت‌ها در پنل پیکو تأیید نشده است.

علت تأییدشده در کد: استخراج تعداد فقط «عدد/عددی/تایی/pcs/pieces» را پوشش می‌دهد؛ «برگ/برگی» نامعلوم می‌ماند و امتیاز نوع/برند مشترک می‌تواند نتیجه را بپذیرد. تفاوت شیت/رولی هم هنوز ویژگی مستقل نیست. این بخش در درخواست تست اصلاح نشد.

## جمع‌بندی پوشش

- کنترل خودکار اصلاحات: موفق.
- تشخیص زنده روی دو محصول دیجی‌کالا و یک محصول/یک دسته‌بندی ات‌کالا: مشاهده شد.
- پنل واقعی، قیمت کارت در برابر مقصد، فیلترها و هدر نصب‌شده: تأیید کامل ممکن نبود؛ دسترسی ابزار به صفحه داخلی افزونه محدود است.
- R06: هنوز باز، یک نقص تعداد مشخص بازتولید شد؛ فهم همه نوع‌ها/برندها تضمین نشده است.
- R08: طبق خواسته مالک skip؛ هیچ تغییری انجام نشده است.

این جلسه مجوز «همه مشکلات رفع شدند» یا انتشار عمومی نیست. قدم بعدی پیشنهادی: تست شکست‌خورده و اصلاح تعداد برگ/برگی، سپس بازتست واقعی پنل.
