# سابقهٔ محصولات پیکو — ۱۹ اکتبر ۲۰۲۶

عنوان «آخرین محصولات دیده‌شده» طبق تصمیم کاربر حفظ شده است.

## رفتار ثبت

- تشخیص محصول و بازدید عادی صفحه، سابقه ایجاد نمی‌کنند.
- بازکردن دستی پنل از ویجت یا آیکن افزونه، محصول همان صفحه را ثبت می‌کند؛ حتی اگر نتیجهٔ جست‌وجو قبلاً در کش باشد.
- اگر تشخیص محصول بعد از بازشدن پنل تمام شود، همان محصول ثبت می‌شود.
- جابه‌جایی به صفحهٔ دیگر یا جست‌وجوی خودکار، تعامل جدید محسوب نمی‌شود.
- تصویر و قیمتِ دیررس محصول ثبت‌شده به‌روز می‌شوند، بدون تغییر ترتیب یا زمان ثبت.
- قیمت سابقه یک snapshot از آخرین خواندن صفحه است؛ نمایش فهرست، استعلام زندهٔ قیمت انجام نمی‌دهد.
- لینک کارت‌های دیما و باسلام از سازوکار همکاری در فروش موجود استفاده می‌کند. لینک امضاشدهٔ افیلیو فقط برای مقصد دقیقاً یکسان از نتایج یا نتایج کش‌شده ذخیره می‌شود؛ بدون لینک معتبر، مقصد مستقیم حفظ می‌شود. قیمت، زمان و ترتیب سابقه با افزودن لینک تغییر نمی‌کنند.
- URL تمیزشده از پارامترهای رهگیری مبنای حذف تکراری است؛ محصول همنام از URL دیگر مستقل می‌ماند.
- آخرین ۱۰ مورد محلی نگهداری و ۴ مورد در کارت نمایش داده می‌شود؛ بازکردن دوباره، مورد قبلی را به ابتدای فهرست می‌آورد.
- جست‌وجوی دستی بدون URL محصول، وارد این فهرست محصول‌ها نمی‌شود.
- پاک‌کردن موفق، فهرست را خالی می‌کند و متادیتای دیررس یا پاسخ خواندن قدیمی آن را برنمی‌گرداند. خطای پاک‌کردن، موارد را پنهان نمی‌کند.
- داده‌های موجود قبلی خودکار حذف نشده‌اند؛ ممکن است شامل بازدیدهای ثبت‌شده با رفتار قدیم باشند. کاربر می‌تواند با دکمهٔ پاک کردن، سابقه را از نو شروع کند.

## ظاهر و حالت خالی

از زمینهٔ سفید، سبز پیکو، لایه‌های سبز روشن، فونت موجود یکان‌بخ، کارت‌های نرم و آیکن‌های خطی استفاده شده است؛ وابستگی و تصویر خارجی جدید اضافه نشده است.

حالت اولین استفاده: «هنوز محصولی اینجا نیست» با توضیح کوتاه و دکمهٔ بازکردن بخش راهنما.

حالت پس از پاک‌کردن: «سابقه‌ات پاک شد»، همراه با اعلام وضعیت و راهنمای شروع دوباره.

راهنما بالاتر از سابقه قرار دارد؛ متن و خط جداکنندهٔ پایین کارت سابقه حذف شده‌اند. دکمهٔ راهنمای حالت خالی مطابق نمونهٔ کاربر مشکی با متن سفید و فرم کپسولی است. «پاک کردن» یک دکمهٔ متنی، بدون آیکن و پس‌زمینه است. کارت‌ها عنوان یک‌خطی و سه‌نقطه‌دار دارند؛ متن کامل در title و لینک محصول قابل دسترسی است. لینک امن در تب جدید، تصویر جایگزین، قیمت نامشخص، فوکوس صفحه‌کلید و کنترل‌های واقعی button حفظ شده‌اند. متن ذخیره‌شده با textContent ساخته می‌شود، نه HTML تزریقی. متن نام/فروشگاه جهت خودکار دارد.

## بررسی

کنترل بستن سربرگ ۳۲×۳۲ پیکسل است. دکمهٔ کنار آن بین محصول/نتایج و راهنما/سابقه جابه‌جا می‌شود؛ نتایج و فیلترها حفظ می‌شوند و پاسخ‌های دیررس جست‌وجو راهنما را نمی‌بندند. در نبود محصول فعال، دکمهٔ رفت‌وبرگشت غیرفعال است.

به‌روزرسانی کارت‌ها طبق نمونهٔ کاربر: تصویر سمت راست ۶۴ پیکسل است؛ پس از امتحان ۷۲ پیکسل، برای جمع‌وجورشدن کارت‌ها کمی کوچک‌تر شد و همچنان از تصویر اولیهٔ ۴۸ پیکسلی بزرگ‌تر است. فاصلهٔ کارت‌ها ۶، فاصلهٔ عکس تا متن ۸ و فاصلهٔ دو ردیف متن ۴ پیکسل است. padding طبق تصویر کاربر: چپ ۱۶ و بالا، راست و پایین ۸ پیکسل. عنوان محصول در ردیف بالا و نام فروشگاه و قیمت در ردیف زیر، روبه‌روی هم قرار دارند. عنوان یک‌خطی با سه‌نقطه و title کامل است؛ فلش تزئینی حذف شده است. قیمت ۱۴ پیکسل با وزن ExtraBold یکان‌بخ است. چیدمان کارت نتایج جست‌وجو تغییر نکرده است.

```bash
npm run test:history
npm test
npm run build:dev
```

تست منطقی از storage و زمان ثابت استفاده می‌کند؛ شبکه و پروفایل شخصی مرورگر درگیر نیستند. تست رابط، HTML/CSS/JS واقعی پنل را با دادهٔ ساختگی در Chrome موقت بررسی می‌کند: حالت خالی/پر/پاک‌شده، خطای پاک‌کردن، پاسخ دیررس، راهنما، محتوای ناامن و عرض‌های ۳۸۰، ۴۲۰ و ۶۰۰ پیکسل. نصب مجدد افزونه یا تغییر production بخشی از این اصلاح نیست.
