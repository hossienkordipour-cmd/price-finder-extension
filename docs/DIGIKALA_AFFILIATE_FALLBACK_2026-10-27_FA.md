# رفع نبود لینک افیلیو برای محصول 7158804

## بازتولید و علت

گزارش: کارت دیجی‌کالا برای قرص ویتامین D3 یوروویتال با لینک مستقیم باز می‌شد. محیط بررسی Windows، شاخهٔ محلی مانیتورینگ و ساخت DEV است.

در ۲۰۲۶/۱۰/۲۷ پاسخ واقعی `api.piqoo.ir/v1/search` بررسی شد: نام کامل شامل برند و مدل و عبارت شش‌کلمه‌ای، پاسخ HTTP 200 با صفر نتیجه داشتند. عبارت کوتاه «قرص ویتامین D3» ۱۹ نتیجه داشت؛ یکی لینک افیلیو متعلق به همان `dkp-7158804` با قیمت ۱۶۰٬۰۰۰ تومان بود. عنوان فید «قرص ویتامین D3-1000 واحدی بسته 60 عددی» است و برند/مدل عنوان صفحه را ندارد. بنابراین این مورد از قطع API یا تغییر مسیر DEV به localhost نبود.

## تغییر

اگر هر سه جست‌وجوی فعلی افیلیو موفق و خالی باشند، فقط یک بار سه کلمهٔ اول عنوان جست‌وجو می‌شود. هنگام خطای شبکه یا محدودیت سرویس، درخواست اضافه‌ای ایجاد نمی‌شود. مسیر تأیید قیمت و ادغام براساس DKP همچنان لینک دریافتی همان محصول را عیناً حفظ می‌کند. در نبود لینک یا شکست جست‌وجوی جایگزین، نتیجهٔ مستقیم قابل استفاده می‌ماند. لینک امضاشده‌ای در این سند ذخیره نشده است.

کلید کش نتایج به V20 تغییر کرد تا نتیجهٔ مستقیم قبلی دوباره استفاده نشود. برای استفاده، `npm run build:dev` و سپس Reload افزونهٔ نصب‌شده از `dist/dev` و Refresh صفحهٔ محصول لازم است. سرویس اصلی یا نسخهٔ Chrome Web Store با این کار منتشر نمی‌شود.

## اعتبارسنجی

`node test/digikala-affiliate-fallback.test.mjs` پیش از تغییر، در شرط نبود جست‌وجوی کوتاه شکست خورد و پس از تغییر پاس شد. شبکه در تست ثابت است؛ نام محصول، DKP و پاسخ فید از مورد واقعی گرفته شده‌اند، امضا ساختگی است. تست حفظ لینک کامل، قیمت تأییدشده، حذف تکراری، محدودبودن درخواست‌ها، حفظ نتیجهٔ مستقیم در حالت خالی و شکست شبکه را بررسی می‌کند. کامیت معرفی‌کننده مشخص نشده؛ رفتار جست‌وجوی شش‌کلمه‌ای در کد موجود دیده شد و تغییرات ثبت‌نشدهٔ دیگر جابه‌جا نشدند. آزمون خودکار بستهٔ نصب‌شده در مرورگر کاربر انجام نشده است.
