# چک‌لیست انتشار افزونه PIQO در Chrome Web Store

این سند مرجع آماده‌سازی و انتشار افزونه PIQO است. هر مرحله فقط پس از توضیح اثر، ریسک‌ها و دریافت تأیید انجام می‌شود.

## وضعیت‌ها

- `[ ]` انجام‌نشده
- `[-]` در حال انجام یا نیازمند بررسی
- `[x]` انجام‌شده و تأییدشده

## هدف واحد افزونه

> PIQO محصول موجود در صفحه یا عبارت واردشده توسط کاربر را شناسایی می‌کند و قیمت و موجودی آن را میان فروشگاه‌های پشتیبانی‌شده مقایسه می‌کند.

همکاری در فروش، روش درآمدزایی PIQO است و بخشی مستقل از هدف اصلی محسوب نمی‌شود. این موضوع باید پیش از نصب، در صفحه Chrome Web Store و داخل رابط افزونه به‌صورت شفاف افشا شود.

افزونه Phia صرفاً به‌عنوان مرجع عمومی برای بررسی الگوهای معرفی محصول، تجربه نصب، رابط کاربری، حریم خصوصی و Store Listing استفاده می‌شود. کد، متن، تصاویر، طراحی یا هویت تجاری آن نباید کپی شود.
