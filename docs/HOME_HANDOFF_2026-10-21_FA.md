# تحویل ادامهٔ توسعهٔ پیکو از سیستم خانه

مخزن: https://github.com/hossienkordipour-cmd/price-finder-extension

این سند همراه تغییرات همین نوبت کامیت می‌شود. شناسهٔ دقیق کامیت حاوی سند را با `git log -1 --oneline -- docs/HOME_HANDOFF_2026-10-21_FA.md` پیدا کنید. کامیت قبلی `39d8c50`، مربوط به افزودن راهنما و سابقه، نیز در تاریخچهٔ develop قرار دارد. برای ادامه، آخرین develop را دریافت کنید؛ به کامیت قدیمی برنگردید.

## خلاصهٔ خروجی تغییرات

### افزونهٔ اصلی: سابقه و راهنما

- عنوان «آخرین محصولات دیده‌شده» حفظ شده است. سابقه تنها با بازکردن دستی پیکو روی محصول ثبت می‌شود، نه هر بازدید معمولی از صفحه.
- ثبت دیررس محصول، به‌روزرسانی عکس/قیمت بدون جابه‌جایی ترتیب، حذف تکراری بر اساس URL و جلوگیری از برگشت سابقهٔ پاک‌شده پیاده شده‌اند.
- ۱۰ محصول نگهداری و ۴ مورد نمایش داده می‌شود. قیمت سابقه snapshot آخرین خواندن صفحه است؛ نمایش سابقه استعلام زنده انجام نمی‌دهد.
- لینک‌های همکاری در فروش با سازوکار موجود دیما/باسلام استفاده می‌شوند؛ لینک امضاشدهٔ افیلیو فقط برای مقصد دقیقاً منطبق نگهداری می‌شود. بدون لینک معتبر، مقصد مستقیم باقی می‌ماند.
- کارت‌های سابقه جمع‌وجورترند: تصویر ۶۴ پیکسلی با fill، عنوان یک‌خطی و سه‌نقطه، قیمت روبه‌روی فروشگاه، padding چپ ۱۶ و بقیه ۸، فاصلهٔ کارت‌ها ۶ پیکسل.
- حالت خالی، پاک‌کردن امن با مدیریت خطا/پاسخ دیررس، دکمهٔ متنی طوسی «پاک کردن» و هاور هم‌سبک کارت‌های اصلی اضافه/اصلاح شده‌اند.
- راهنما بالاتر از سابقه است؛ متن توضیحی/جداکنندهٔ پایین سابقه و پیام موفقیت پایین حذف شده‌اند. عنوان حالت خالی پس از پاک‌کردن هنوز «سابقه‌ات پاک شد» است.
- سربرگ صفحهٔ راهنما، دکمهٔ رفت‌وبرگشت، آیکن راهنما و رنگ یکسان آیکن‌ها اصلاح شده‌اند. در دسکتاپ دکمه‌ها ۳۲×۳۲ و آیکن داخلشان ۱۴ پیکسل‌اند؛ در شیت موبایل اندازهٔ لمس دکمه‌ها ۴۰ پیکسل است.
- تایپوگرافی از فایل‌های موجود یکان‌بخ و وزن‌های تعریف‌شده استفاده می‌کند. تطابق نهایی فونت با فایل Figma روی سیستم خانه باید در صورت نیاز دوباره بصری بررسی شود؛ آرشیو RAR ارسالی کاربر جزو مخزن نیست.

### افزونهٔ اصلی: موبایل و قیمت

- در عرض صفحهٔ میزبان تا ۶۰۰ پیکسل، پنل به باتم‌شیت تمام‌عرض با ارتفاع اولیهٔ ۷۶٪ و حالت بازتر ۹۴٪ تبدیل می‌شود؛ معیار عرض iframe نیست.
- لایهٔ تیره، قفل اسکرول پشت پنل، هدر/دستگیرهٔ ثابت، اسکرول داخلی، safe area و کاهش حرکت اضافه شده‌اند.
- بستن با ضربدر، بیرون پنل، Escape و کشیدن دستگیره به پایین؛ بزرگ‌کردن با دستگیره/کشیدن به بالا؛ حفظ نتایج هنگام resize و مدیریت بازوبسته‌شدن سریع تست شده‌اند.
- قیمت دیجی‌کالا در DOM موبایل از `data-theme-animation="price-container"` هم خوانده می‌شود، در محدودهٔ پیشنهاد انتخاب‌شده. قیمت بیمه، خط‌خورده یا فروشندهٔ دیگر نباید جای قیمت اصلی بنشیند؛ قیمت ناموجود/مبهم همچنان نامشخص می‌ماند.

### آموزش تعاملی مستقل

- صفحهٔ فروشگاه کامل با عکس واقعی AirPods Pro، لایهٔ تیرهٔ شروع و تمرکز روی ویجت پیکو ساخته شده است.
- فلو: بازکردن پیکو ← انتظار کوتاه بدون راهنمای موقت ← نتایج تک‌ستونه ← انتخاب پیشنهاد اول ← فروشگاه دوم با طراحی متفاوت آوا مارکت ← کاغذرنگی و کارت پایان در سمت چپ.
- ظاهر پنل به افزونهٔ اصلی نزدیک شده است. مرتب‌سازی و تغییر چیدمان قابل امتحان‌اند؛ دو پیشنهاد کم‌رنگ دوم و سوم غیرفعال‌اند و نباید با کلیک وارد مقصد شوند.
- کارت پایان اختلاف نمایشی ۱٬۶۰۰٬۰۰۰ تومان را نشان می‌دهد و دکمهٔ «حالا واقعی امتحانش کن» به محصول آیفون ۱۷ دیجی‌کالا با شناسهٔ `20127115` و واریانت `74448669` می‌رود.
- لینک «پیکو رو نداری؟ نصبش کن» به Chrome Web Store با شناسهٔ `kdgpgfdmcobfnklpbkmjbphoebnlgkki` می‌رود.
- قیمت‌ها و فروشگاه‌های آموزش ساختگی‌اند؛ API/خرید واقعی در خود آموزش اجرا نمی‌شود. تکرار، لغو بارگذاری، کیبورد و حالت کاهش حرکت پوشش داده شده‌اند.
- اعتبار عکس و مجوز آن در `tutorial/assets/PHOTO-LICENSE.txt` و فوتر حفظ شود. انتشار عمومی فونت/دارایی‌ها نیز پیش از استقرار بررسی شود.

## باگ‌های باز؛ هنوز اصلاح نشده‌اند

۱. **حالت افقی گوشی:** با چرخش از 390×844 به 844×390، شرط عرض ۶۰۰ باعث تبدیل شیت به پنل دسکتاپ ۳۸۲ پیکسلی و حذف بک‌دراپ می‌شود. باید سیاست تشخیص حالت موبایل/افقی تعیین و با تست رگرسیون اصلاح شود؛ پنل باریک دسکتاپ نباید اشتباهاً موبایل تشخیص داده شود.

۲. **فوکوس پشت شیت:** با شیت باز، Shift+Tab می‌تواند به دکمهٔ صفحهٔ میزبان برسد، در حالی که بک‌دراپ فعال است. ورود فوکوس به پنل، محدودکردن فوکوس/تعامل پشت آن و بازیابی درست وضعیت هنگام بستن، حذف و resize باید اصلاح و تست شوند. این مشکل در آموزش مستقل با افزونهٔ اصلی یکی نیست؛ آموزش منطق فوکوس جدا دارد.

تست audit این دو وضعیت را گزارش می‌کند اما عمداً کل مجموعه را fail نمی‌کند. پاس‌شدن تست‌ها به معنی رفع این دو باگ نیست.

## دریافت و اجرا روی سیستم خانه

ابتدا وضعیت Git و دستورهای محلی AGENTS.md را بررسی کنید. اگر تغییر محلی وجود دارد آن را حذف، reset یا stash خودکار نکنید. سپس در ریشهٔ مخزن تمیز:

```powershell
git fetch origin
git switch develop
git pull --ff-only origin develop
git status --short --branch
git log -3 --oneline
npm.cmd ci
npm.cmd test
npm.cmd run build:dev
```

اگر develop محلی وجود ندارد، به‌جای switch بالا از `git switch --track origin/develop` استفاده کنید. اگر تاریخچه diverge شده، توقف و اختلاف را بررسی کنید؛ force/reset لازم نیست.

در `chrome://extensions` نسخهٔ DEV را از پوشهٔ **`dist/dev`** Load unpacked کنید، یا اگر از همین مسیر نصب است Reload کنید. صفحهٔ محصول را هم Refresh کنید. نسخهٔ عمومی/نصب DEV تکراری هنگام تست هم‌زمان فعال نباشد. مسیر سیستم خانه لزوماً با سیستم محل کار یکسان نیست.

`dist` و `node_modules` در Git نیستند؛ روی خانه دوباره ساخته می‌شوند. Chrome معمول اندروید افزونه اجرا نمی‌کند؛ این حالت responsive نیازمند محیطی است که افزونه را پشتیبانی کند.

برای آموزش:

```powershell
npm.cmd run dev:tutorial
```

آدرس: http://127.0.0.1:4173/tutorial/ . سرور فقط loopback و فایل‌های مجاز آموزش را سرو می‌کند. برای پورت دیگر: `$env:TUTORIAL_PORT='4174'` و اجرای دوبارهٔ دستور. خروجی مستقل با `npm.cmd run build:tutorial` در `dist/tutorial` ساخته می‌شود.

## نتیجهٔ بررسی پیش از کامیت

در همین نوبت همهٔ فرمان‌های زیر موفق بودند:

```powershell
npm.cmd test
npm.cmd run test:history
npm.cmd run test:tutorial
npm.cmd run test:base-price
$env:PIQO_MOBILE_AUDIT='1'
npm.cmd run test:mobile-sheet
Remove-Item Env:PIQO_MOBILE_AUDIT
npm.cmd run build:dev
npm.cmd run build:tutorial
git diff --check
```

تست‌های UI از Chrome موقت با دادهٔ محلی استفاده می‌کنند. مسیر Chrome در بعضی تست‌ها Windows-specific است (`C:/Program Files/Google/Chrome/Application/chrome.exe`)؛ در صورت نبودن Chrome در این مسیر، تست را سازگار کنید و شکست محیط را با باگ محصول یکی ندانید. این تست‌ها تأیید همهٔ قیمت‌ها/نتایج زنده، گوشی واقعی یا Safari/Firefox نیستند. کنترل تب واقعی Chrome در بررسی اخیر قطع شد؛ تأیید سرتاسری روی دستگاه واقعی هنوز لازم است.

## فایل‌های کلیدی و ادامهٔ پیشنهادی

- `content/content.js`: تشخیص محصول/قیمت و قاب باتم‌شیت میزبان.
- `sidebar/sidebar.html`, `sidebar/sidebar.css`, `sidebar/sidebar.js`: UI واقعی افزونه، سابقه، راهنما و پیام‌های شیت.
- `background.js`: ثبت سابقه با تعامل صریح، مدیریت هم‌زمانی و اتصال لینک همکاری در فروش.
- `tutorial/` و `scripts/*tutorial*.mjs`: آموزش مستقل، سرور و ساخت خروجی.
- `test/mobile-sheet.test.mjs`, `test/digikala-base-price.test.mjs`, `test/recent-history*.test.mjs`, `test/tutorial.test.mjs`: تست‌های مرتبط.
- اسناد مکمل: `DEV_INSTALL_HOME_FA.md`, `MOBILE_BOTTOM_SHEET_FA.md`, `RECENT_HISTORY_UX_FA.md`, `TUTORIAL_LOCAL_FA.md`, `TUTORIAL_QA_2026-10-21_FA.md`. برخی بخش‌های این اسناد شرح مراحل قبلی‌اند؛ وضعیت فعلی و محدودیت‌های باز در همین سند آمده است.

این تحویل فقط برای ادامه روی develop است. آموزش هنوز پشت دامنهٔ پیکو مستقر نشده و نسخهٔ عمومی Chrome Web Store با این کار منتشر نمی‌شود.
