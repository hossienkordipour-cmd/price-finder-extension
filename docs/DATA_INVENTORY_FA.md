# فهرست داده‌های پردازش‌شده در افزونه PIQO

این سند رفتار نسخه فعلی افزونه را برای تکمیل Privacy Policy و بخش Data Usage در Chrome Web Store ثبت می‌کند. منظور از «پردازش» در این سند، خواندن، استفاده، انتقال یا ذخیره داده است؛ حتی اگر داده مستقیماً هویت کاربر را مشخص نکند.

## خلاصه

- افزونه برای تشخیص محصول، محتوای عمومی صفحه محصول را می‌خواند.
- جست‌وجوی قیمت فقط بعد از بازکردن پنل افزونه یا ثبت جست‌وجوی دستی آغاز می‌شود.
- عبارت جست‌وجو برای دریافت قیمت به API متعلق به PIQO و سرویس‌های فروشگاهی فعال ارسال می‌شود.
- افزونه حساب کاربری ندارد و نام واقعی، ایمیل، شماره تلفن، رمز عبور، اطلاعات بانکی، مخاطبان یا موقعیت واقعی کاربر را درخواست یا جمع‌آوری نمی‌کند.
- داده‌های محلی در `chrome.storage.local` ذخیره می‌شوند و با Chrome Sync همگام نمی‌شوند.

## داده‌های صفحه محصول

| داده | منبع | هدف | انتقال | نگهداری محلی |
|---|---|---|---|---|
| نام محصول | عنوان صفحه، `h1`، Open Graph، Schema.org یا عناصر فروشگاه | تشخیص محصول و ساخت عبارت جست‌وجو | نام یا عبارت ساخته‌شده به سرویس‌های جست‌وجوی فعال ارسال می‌شود | در وضعیت همان تب و کش جست‌وجو |
| قیمت مشاهده‌شده | عناصر قیمت یا Schema.org | تطبیق و حذف نتایج نامرتبط | به‌صورت مستقیم برای جست‌وجو ارسال نمی‌شود | در وضعیت همان تب |
| تصویر محصول | Open Graph، Schema.org یا تصویر صفحه | نمایش محصول در رابط افزونه | به‌صورت مستقیم برای جست‌وجو ارسال نمی‌شود | URL تصویر در وضعیت همان تب |
| نام یا دامنه فروشگاه | دامنه صفحه یا Parser اختصاصی | نمایش منبع محصول و ساخت شناسه داخلی | به‌صورت مستقیم برای جست‌وجو ارسال نمی‌شود | در وضعیت همان تب |
| URL محصول | Canonical هم‌دامنه یا URL فعلی پس از حذف پارامترهای رهگیری شناخته‌شده و Fragment معمولی | تشخیص تغییر محصول و نگهداری وضعیت تب | برای جست‌وجوی قیمت به PIQO API یا فروشگاه‌ها ارسال نمی‌شود | در وضعیت همان تب؛ با بسته‌شدن تب حذف می‌شود |

URLهای Canonical فقط در صورت `http` یا `https` بودن و یکسان‌بودن Origin پذیرفته می‌شوند. پارامترهای رهگیری شناخته‌شده مانند `utm_*`، `gclid`، `fbclid` و شناسه‌های مشابه حذف می‌شوند. پارامترهای کاربردی ناشناخته ممکن است باقی بمانند و Hashهای مسیریابی SPA مانند `#/` حفظ می‌شوند.

## جست‌وجوی دستی و سرویس‌های مقصد

متن واردشده در جست‌وجوی دستی مانند نام محصول پردازش می‌شود. عبارت اصلی ممکن است برای افزایش کیفیت نتیجه پاک‌سازی یا کوتاه شود.

در جست‌وجوی فعال فعلی، عبارت محصول به این مقصدها ارسال می‌شود:

- `api.piqoo.ir`؛ سه نسخه از عبارت جست‌وجو برای دریافت نتایج همکاری در فروش
- API جست‌وجوی دیجی‌کالا
- API جست‌وجوی ترب
- صفحه نتایج ایمالز
- APIهای جست‌وجوی باسلام
- API جست‌وجوی دیوار؛ عبارت در بدنه درخواست `POST` قرار می‌گیرد
- API جست‌وجوی شیپور
- API جست‌وجوی اسنپ‌شاپ
- API جست‌وجوی مسترکالا؛ عبارت در بدنه درخواست `POST` قرار می‌گیرد
- صفحه جست‌وجوی دیجی‌پی
- API فروشگاه کالائوما

کدهای جست‌وجوی خانومی، تکنولایف و روژاشاپ در مخزن وجود دارند، اما در فهرست جست‌وجوی فعال نسخه فعلی فراخوانی نمی‌شوند.

## داده‌های نتایج جست‌وجو

پاسخ سرویس‌ها می‌تواند شامل نام محصول، قیمت، قیمت قبلی، درصد تخفیف، تصویر، URL خرید، موجودی، نو یا کارکرده بودن، امتیاز و تعداد نظر باشد. این داده‌ها برای نمایش، تطبیق، مرتب‌سازی و حذف نتایج تکراری استفاده می‌شوند.

- وضعیت هر تب شامل محصول فعلی، نتایج، وضعیت بارگذاری، خطا، شناسه داخلی درخواست و زمان به‌روزرسانی است.
- وضعیت تب در `chrome.storage.local` ذخیره و هنگام بسته‌شدن همان تب حذف می‌شود.
- کش جست‌وجو حداکثر ۳۰ ورودی دارد و نتیجه‌ای که بیش از ۱۰ دقیقه از آن گذشته باشد دوباره استفاده نمی‌شود.
- ورودی منقضی‌شده ممکن است تا نوشتن بعدی کش از حافظه محلی حذف فیزیکی نشود.

## لاگ‌های فنی محلی

افزونه حداکثر ۳۰۰ لاگ درخواست API را در `chrome.storage.local` نگه می‌دارد. هر لاگ می‌تواند شامل نام سرویس، URL درخواست، روش HTTP، نوع عملیات، زمان، مدت، وضعیت پاسخ، خطا و تعداد نتیجه باشد.

- کلیدهای حساس شناخته‌شده مانند `token`، `access_token`، `api_key` و `authorization` در URL لاگ مخفی می‌شوند.
- عبارت جست‌وجو و کلید کش می‌توانند در لاگ باقی بمانند.
- برای این لاگ‌ها در نسخه فعلی زمان انقضای جداگانه تعریف نشده است؛ فقط ۳۰۰ ورودی آخر حفظ می‌شوند و امکان پاک‌کردن آن‌ها در کد وجود دارد.

## وضعیت نصب و Onboarding

افزونه زمان نصب و وضعیت‌های `completed` و `nudgeShown` را همراه زمان رخدادهای مربوط در `chrome.storage.local` ثبت می‌کند. این داده صرفاً برای کنترل تجربه Onboarding است و به سرور ارسال نمی‌شود.

صفحه Onboarding سایت PIQO فقط چهار عبارت ثابت نمونه را از افزونه درخواست می‌کند. افزونه این عبارت‌های ثابت را با دیجی‌کالا جست‌وجو می‌کند و محصولات پیشنهادی را به همان صفحه و همان Origin برمی‌گرداند.

## کوکی، موقعیت و اطلاعات فنی شبکه

- افزونه از API کوکی Chrome استفاده نمی‌کند و مقدار کوکی‌ها را مستقیماً نمی‌خواند.
- درخواست مستقیم اسنپ‌شاپ با `credentials: "include"` اجرا می‌شود؛ در نتیجه مرورگر ممکن است کوکی موجود همان دامنه را همراه درخواست برای اسنپ‌شاپ ارسال کند.
- درخواست اسنپ‌شاپ دارای مختصات ثابت `35.6969675, 51.4080675` است. این مقدار ثابت است و موقعیت واقعی دستگاه یا کاربر خوانده نمی‌شود.
- مانند هر ارتباط وب، سرویس مقصد می‌تواند اطلاعات فنی معمول درخواست، از جمله IP عمومی، User-Agent و زمان درخواست را در سطح شبکه مشاهده یا لاگ کند. افزونه این اطلاعات را جداگانه استخراج نمی‌کند.

## API متعلق به PIQO و کش سرور

افزونه عبارت جست‌وجو را از طریق HTTPS به `api.piqoo.ir` می‌فرستد. طبق مستندات فعلی بک‌اند:

- نتایج دارای محصول ۳ دقیقه تازه و تا ۱۵ دقیقه به‌صورت stale قابل استفاده‌اند.
- نتیجه خالی ۱ دقیقه کش می‌شود.
- کلید Redis شامل SHA-256 عبارت نرمال‌شده است و متن خام عبارت در نام کلید قرار نمی‌گیرد.
- فیلدهای Authorization، Cookie و شناسه‌های محرمانه Affilio در لاگ برنامه redact می‌شوند.

مدت نگهداری لاگ‌های Nginx، Docker یا زیرساخت سرور از کد این افزونه قابل تأیید نیست و باید پیش از نهایی‌شدن Privacy Policy توسط مالک بک‌اند مشخص شود.

## لینک‌های خرید و همکاری در فروش

برخی URLهای نتیجه، لینک همکاری در فروش هستند. پس از کلیک کاربر، مرورگر به فروشگاه یا سرویس افیلیت هدایت می‌شود و مقصد می‌تواند شناسه عمومی همکاری در فروش و اطلاعات فنی معمول بازدید را دریافت کند. نام محصول نیز ممکن است در پارامتر `utm_term` لینک ساخته‌شده قرار گیرد.

## داده‌هایی که در نسخه فعلی جمع‌آوری نمی‌شوند

- نام واقعی، ایمیل، شماره تلفن و شناسه حساب شخصی
- رمز عبور و اطلاعات احراز هویت
- اطلاعات بانکی، پرداخت یا تراکنش
- مخاطبان، فایل‌ها و محتوای Clipboard
- تاریخچه کامل مرور کاربر
- موقعیت واقعی دستگاه
- صدا، تصویر دوربین یا داده‌های حسگرها
- داده‌های تبلیغاتی یا Analytics مستقل

## موارد لازم برای Privacy Policy

Privacy Policy باید به‌روشنی اعلام کند که نام یا عبارت محصول برای مقایسه قیمت به PIQO و فروشگاه‌های جست‌وجوشده ارسال می‌شود، داده‌های صفحه محصول به‌صورت محلی پردازش می‌شوند، برخی لینک‌ها افیلیت هستند و سرویس‌های مقصد ممکن است اطلاعات فنی معمول شبکه را دریافت کنند. مدت نگهداری لاگ‌های سرور PIQO نیز باید قبل از انتشار نهایی تعیین و ثبت شود.


## افزودهٔ مانیتورینگ و نظرسنجی — ۲۴ اکتبر ۲۰۲۶، فقط پیاده‌سازی محلی

این بخش رفتار جدید را مستند می‌کند و بر توضیحات قدیمی دربارهٔ نبود جمع‌آوری مرکزی اولویت دارد. نسخهٔ استور و سرور تغییری نکرده‌اند.

- دریافت‌کننده: API خود پیکو؛ نسخهٔ dev فقط http://127.0.0.1:3000.
- قرارداد لاگ: schema_version، event_id، event_name، occurred_at، extension_version، search_id و شناسهٔ درخواست/جست‌وجوی شبکهٔ مرتبط؛ منبع محدود، وضعیت طبقه‌بندی‌شده، کش، مدت و تعدادها. زمان دریافت سرور جداست.
- موارد ممنوع در لاگ مرکزی: عنوان و عبارت محصول، URL کامل، متن خطا، کوکی، توکن، اطلاعات تماس و شناسهٔ دائمی کاربر. api-logger.js محلی مستقیماً ارسال نمی‌شود.
- صف: chrome.storage.local با کلید piqoDiagnosticsV1؛ حداکثر ۴۰۰ رویداد، عمر ۲۴ ساعت، دسته‌های ۴۰تایی، حداکثر ۵ تلاش با فاصلهٔ افزایشی. دریافت قطعی و idempotent در PostgreSQL.
- نظرسنجی: کلید piqoSurveyV1 فقط محلی؛ ۵ جست‌وجوی پایان‌یافته، ۳ روز محلی مجزا، حداکثر دو دعوت با فاصلهٔ ۱۴ روز. پاسخ مستقل شامل بله/خیر، توضیح تا ۱۰۰۰ نویسه، نسخه، زمان و survey_id است؛ search_id و شمارنده‌ها ارسال نمی‌شوند.
- دیتابیس: ۳۰ روز پس از دریافت، پاک‌سازی روزانه؛ بکاپ AES-256-GCM با کلید مستقل، نگهداری ۷ روز، بازیابی بدون احیای دادهٔ منقضی.
- مدیر: یک رمز هش‌شده با scrypt، نشست ۸ساعتهٔ سمت سرور، کوکی HttpOnly/SameSite و Secure در production؛ CSRF برای تغییرات، بدون کلید مدیر در افزونه.
- لاگ و نظرسنجی بدون خرید ابزار Analytics یا ارسال داده به سرویس جدید خارجی ساخته شده‌اند.


### افزودهٔ استفادهٔ زنده و دسته‌ها — ۲۶ اکتبر ۲۰۲۶، فقط نسخهٔ محلی

علاوه بر لاگ فنی، دستهٔ کلی محصول (یا نامشخص)، روش/اطمینان/نسخهٔ تشخیص و شناسهٔ تصادفی موقت جلسه ثبت می‌شود؛ نام محصول و عبارت جست‌وجو برای این آمار ارسال نمی‌شوند. دسته‌بندی روی دستگاه است. شناسه در حافظهٔ جلسهٔ مرورگر، مشترک بین تب‌ها، با چرخش پس از ۳۰ دقیقه بی‌فعالیتی یا ۸ ساعت قرار دارد و شناسهٔ دائمی فرد نیست. هنگام قابل دیدن بودن پنل یا آغاز جست‌وجو، پیام فعالیت محدود ارسال می‌شود.

تعداد فعال‌ها تخمین جلسه‌های دارای فعالیت در ۵ دقیقهٔ اخیر است، نه تعداد دقیق افراد. پیام فعالیت آفلاین صف نمی‌شود؛ حضور موقت پس از یک روز بی‌فعالیتی در پاک‌سازی روزانه حذف می‌شود و وارد بکاپ نیست. دسته و شناسهٔ موقتِ همراه لاگ خام، تابع نگهداری ۳۰روزهٔ همان لاگ‌اند. آمار کلیک یا عنوان کامل محصول اضافه نشده است. این توضیح بر بخش‌های قدیمی دربارهٔ نبود آمار دسته/جلسه اولویت دارد؛ انتشار عمومی هنوز انجام نشده است.
