# دیوار — پوشش مشترک برچسب‌های قیمت فروش

۱۴ اکتبر ۲۰۲۶؛ تغییر محلی روی `codex/digikala-base-price`، منتشر نشده است.

شاهد واقعی: آگهی `gaNDvAq_`، «روا مدل۸۷ تمیز»، ردیف نمایان `.kt-unexpandable-row` با عنوان «قیمت پایه» و مقدار «۳۷۲,۰۰۰,۰۰۰ تومان». کد قبلی فقط عنوان دقیق «قیمت» را می‌پذیرفت؛ تست مبتنی بر همین ردیف قبل از اصلاح null برگرداند و شکست خورد.

اصلاح در `extractDivar` مشترک است؛ URL یا شناسه این آگهی در runtime شرط نشده است. برچسب‌های «قیمت»، «قیمت پایه» و «قیمت کل» پس از پاک‌سازی نشان‌های جهت متن، تبدیل نیم‌فاصله به فاصله، یکسان‌کردن ی/ک عربی و حذف دونقطه پایانی پذیرفته می‌شوند.

فقط مبلغ دارای واحد صریح تومان/ریال از ردیف نمایان خوانده می‌شود. توافقی، رایگان و مبلغ بدون واحد همچنان null هستند. مبالغ ودیعه، اجاره ماهانه، قسط، قیمت هر متر، کارکرد و توضیحات قیمت فروش محسوب نمی‌شوند. اگر دو ردیف قیمت فروش مقادیر متفاوت داشته باشند، عددی حدس زده نمی‌شود.

`test/divar-sale-price.test.mjs`: قبل از اصلاح قرمز و بعد سبز؛ `--without-fix` محدودیت قبلی را در حافظه تست بازسازی و دوباره شکست می‌دهد. تست‌ها fixture ثابت دارند و شبکه خارجی مسدود است؛ ساعت و تصادف در نتیجه دخیل نیستند. ردیف روا واقعاً مشاهده شد؛ حالت‌های «قیمت کل» و گونه‌های نگارشی/اجاره/قسط، کنترل مصنوعی‌اند، نه ادعای بازتست زنده تمام قالب‌های دیوار. تست به `npm run test:divar-product` اضافه شده است.

این اصلاح تشخیص صفحه، عکس، MCP/relay دیوار، نتایج جستجو و برچسب نو/کارکرده را عوض نمی‌کند. قالب‌های ناشناخته هنوز ممکن است قیمت نامشخص داشته باشند؛ پشتیبانی همه آگهی‌های دیوار تضمین نشده است. آگهی اجاره برای نمایش ودیعه و اجاره به ساختار داده و نمایش جدا نیاز دارد.

نسخه سالم تاریخی برای bisect مشخص نیست؛ HEAD پایه فعلی `7e05cdcca51a3f8d8f5554b7088c5dd696009fac` با تغییرات کاری است. بازتست مالک: Reload افزونه DEV و Refresh آگهی روا؛ مبلغ کارت مبنا باید با ردیف قیمت همان لحظه مقایسه شود. مبلغ ۳۷۲ میلیون شاهد زمان بررسی است، نه قیمت ثابت در کد.
