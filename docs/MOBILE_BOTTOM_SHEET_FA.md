# پنل موبایل پیکو

این تغییر مربوط به افزونهٔ اصلی است، نه آموزش تعاملی.

در عرض میزبان تا ۶۰۰ پیکسل، قاب افزونه از پایین باز می‌شود: عرض کامل، ارتفاع اولیهٔ ۷۶٪ فضای قابل‌نمایش و گوشه‌های بالایی گرد. صفحهٔ پشت پنل کمی تیره و اسکرول آن قفل می‌شود. داخل پنل، نتایج اسکرول می‌شوند و هدر/دستگیره بالای صفحه باقی می‌مانند. حاشیهٔ امن پایین دستگاه رعایت می‌شود.

دستگیره با کلیک/کیبورد بین ارتفاع ۷۶٪ و ۹۴٪ جابه‌جا می‌شود؛ کشیدن به بالا آن را بازتر می‌کند و کشیدن بیش از ۷۲ پیکسل به پایین می‌بندد. بستن با ضربدر، Escape و لمس لایهٔ بیرون هم امکان‌پذیر است. هنگام بستن یا حذف UI، وضعیت اسکرول قبلی صفحه برمی‌گردد. حالت کاهش حرکت رعایت می‌شود.

معیار موبایل عرض **صفحهٔ میزبان** است، نه عرض iframe؛ در نتیجه قاب ۳۸۰ پیکسلی دسکتاپ اشتباهاً شیت نمی‌شود. با تغییر اندازه بدون بارگذاری دوبارهٔ iframe، چیدمان عوض می‌شود و نتایج و فیلترها حفظ می‌شوند. پیام بستن/تغییر ارتفاع فقط از پنجرهٔ همان iframe پذیرفته می‌شود.

## بررسی و استفاده

`npm run test:mobile-sheet` فایل‌های واقعی قاب، HTML/CSS و JavaScript پنل را با داده‌های آزمایشی محلی در Chrome موقت بررسی می‌کند: عرض‌های ۳۲۰، ۳۹۰ و ۶۰۰، دسکتاپ ۱۲۸۰، بازترکردن، اسکرول، راهنما، سوایپ، ضربدر، لمس بیرون، Escape، بستن/بازکردن سریع، تغییر اندازه، کاهش حرکت و پاک‌سازی.

پس از `npm run build:dev`، افزونهٔ DEV نصب‌شده از `dist/dev` را در صفحهٔ افزونه‌های Chrome Reload و صفحهٔ فروشگاه را رفرش کنید. اگر مسیر نصب خود ریشهٔ مخزن است، همان افزونه را Reload کنید. این کار قابلیت نصب افزونه به Chrome موبایل اضافه نمی‌کند؛ نیاز به مرورگری دارد که افزونه را اجرا کند. بررسی حاضر شبیه‌سازی عرض موبایل در Chrome است، نه تست روی سخت‌افزار گوشی. نسخهٔ فروشگاه Chrome منتشر نشده است.
