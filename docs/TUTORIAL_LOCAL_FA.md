# آموزش تعاملی پیکو — نسخهٔ محلی

این صفحه یک دموی مستقل است؛ افزونه را نصب نمی‌کند، به API وصل نمی‌شود، اطلاعات کاربر را ذخیره نمی‌کند و خرید/لینک همکاری در فروش ندارد. مدل و عکس محصول واقعی‌اند؛ فروشگاه‌ها، موجودی و قیمت‌ها ساختگی‌اند و این موضوع در صفحه اعلام می‌شود.

## اجرا

```bash
npm run dev:tutorial
```

آدرس: http://127.0.0.1:4173/tutorial/

سرور فقط روی loopback گوش می‌دهد و فقط فایل‌های مجازِ دمو را سرو می‌کند، نه بقیهٔ ریپازیتوری. برای توقف Ctrl+C بزن. برای پورت دیگر متغیر `TUTORIAL_PORT` را تنظیم کن.

## فلو

۱. محصولی با عکس واقعی AirPods Pro و قیمت نمایشی ۱۲٬۴۹۰٬۰۰۰ تومان نشان داده می‌شود؛ کاربر روی «ارزون‌ترش هست؟» می‌زند.
۲. پس از یک انتظار کوتاه نمایشی، سه پیشنهاد ثابت نشان داده می‌شود. مرتب‌سازی قابل امتحان است.
۳. انتخاب هر پیشنهاد، فروشگاه و قیمت صفحهٔ نمونه و پیام صرفه‌جویی را مطابق همان پیشنهاد تغییر می‌دهد؛ صفحهٔ واقعی فروشنده باز نمی‌شود.
۴. «تکرار آموزش» تمرین را ریست می‌کند. کارت پایان مبلغ صرفه‌جوییِ نمایشی را برجسته نشان می‌دهد. دکمهٔ «حالا واقعی امتحانش کن» با کلیک مستقیم کاربر صفحهٔ آیفون ۱۷ در دیجی‌کالا (محصول 20127115، واریانت 74448669، لینک انتخابی کاربر) را در تب جدید باز می‌کند تا افزونهٔ نصب‌شده را روی آن امتحان کند. لینک نصب پیکو نیز جداگانه در کارت است. هیچ صرفه‌جویی واقعی تضمین نمی‌شود.

پس از انتخاب پیشنهاد، کاغذرنگی با حرکت چرخشی و تاب‌خوردن از بالا می‌ریزد؛ پس از حداکثر ۸ ثانیه پاک می‌شود. انیمیشن جلوی کلیک را نمی‌گیرد، با تکرار آموزش پاک می‌شود و در حالت کاهش حرکت اصلاً اجرا نمی‌شود.

بستن پنل یا Escape به قدم اول برمی‌گردد. تایمر جست‌وجوی قبلی نمی‌تواند تمرین ریست‌شده را تغییر دهد. همهٔ فونت‌ها و تصاویر محلی‌اند؛ فونت و لوگو از دارایی‌های فعلی افزونه استفاده می‌کنند.

فروشگاه تمام‌عرض و بدون قاب بیرونی آموزش نمایش داده می‌شود. از قدم اول، لایهٔ تیره روی فروشگاه قرار می‌گیرد و فقط دکمهٔ پیکو و راهنمای قدم روشن می‌مانند. محتوای زیر این لایه از مسیر کیبورد خارج است؛ پس از انتخاب پیشنهاد، لایه برداشته می‌شود و فروشگاه دوم قابل تعامل است.

در نسخهٔ دوم، راهنمای دسکتاپ کنار هدف همان قدم قرار می‌گیرد و با تغییر چیدمان، اسکرول پنل و اندازهٔ صفحه جابه‌جا می‌شود. در موبایل، راهنما پایین پنل است و ارتفاع واقعی‌اش برای جلوگیری از هم‌پوشانی رزرو می‌شود. پنل به اندازه‌ها و تایپوگرافی افزونه نزدیک شده؛ مرتب‌سازی مرتبط‌ترین/قیمت و حالت شبکه‌ای کار می‌کنند. بعد از انتخاب، رنگ و چیدمان فروشگاه دوم عوض می‌شود و خلاصهٔ قیمت اول، قیمت انتخابی و صرفه‌جویی نمایش داده می‌شود. Tab داخل پنل و راهنما می‌ماند و Escape تمرین را ریست می‌کند.

عکس واقعی از Wikimedia Commons، اثر Arne Müseler / arne-mueseler.com، با مجوز CC BY-SA 3.0 DE است. اعتبار عکاس و لینک مجوز در فوتر قابل مشاهده‌اند و اطلاعات کامل در `tutorial/assets/PHOTO-LICENSE.txt` قرار دارند. فایل دانلودشده دست‌نخورده است؛ CSS آن را در قاب نمایش می‌دهد. استفاده از عکس هیچ تأییدی از طرف عکاس یا اپل نسبت به پیکو یا فروشگاه‌ها/قیمت‌های ساختگی نیست. در زمان انتشار، اعتبار و مجوز عکس حفظ شوند.

## خروجی مستقل و انتقال بعدی

```bash
npm run build:tutorial
```

خروجی کامل در `dist/tutorial/` است و به فایل‌های بیرون این پوشه وابسته نیست. می‌توان بعد از تأیید طراحی، آن را به مسیر `/tutorial/` در هاست پیکو منتقل کرد یا محتوایش را در پروژهٔ سایت ادغام کرد. برای انتشار باید تنظیمات هاست، کش/هدرهای امنیتی و مجوز انتشار فونت بررسی شوند؛ این کار هنوز انجام نشده است. لینک فعلی راهنمای افزونه عمداً تغییر نکرده است.

## تست

```bash
npm run test:tutorial
```

تست با Chrome موقت و سرور موقت، فلو کامل، مقادیر صرفه‌جویی، مرتب‌سازی، شروع دوباره، بستن هنگام بارگذاری، کیبورد، اندازه‌های موبایل/دسکتاپ، کاهش حرکت و نبود درخواست خارجی را بررسی می‌کند. به پروفایل شخصی مرورگر متصل نمی‌شود.
