# R05 — تشخیص محصول ات‌کالا

تاریخ: ۲۰۲۶-۱۰-۱۴. اصلاح محلی روی برنچ `codex/digikala-base-price`؛ منتشر نشده است.

## شاهد و علت

صفحه `/products/312702/…` در مرورگر داخل برنامه باز شد: عنوان «رول فیلم استرچ محافظ غذایی ۵۰ متری آیری پلاست»، قیمت فروش ۳۰۰٬۰۰۰ تومان و قیمت خط‌خورده ۶۰۰٬۰۰۰ تومان.
متادیتای صفحه `og:type=website`، عنوان عمومی فروشگاه و تصویر `og.jpg` است؛ JSON-LD محصول وجود ندارد. استخراج عمومی به همین دلیل محصول را شناسایی نمی‌کرد.
مرورگر آزمایشی مستقل با پاسخ 500 و «دسترسی شما محدود شده است» مواجه شد؛ این محدودیت جدا از باگ تشخیص است.

## اصلاح

- استخراج اختصاصی فقط برای دامنه ات‌کالا و مسیر `/products/<id>`.
- عنوان از `h1` و تصویر از گالری `product-image-0`، نه عنوان و لوگوی فروشگاه.
- قیمت فروش از محدوده دکمه اصلی سبد و واحد صریح؛ قیمت خط‌خورده و کارت‌های مرتبط وارد محاسبه نمی‌شوند.
- قیمت نامعلوم یا ناموجود نامشخص می‌ماند؛ تغییرات همان صفحه دوباره خوانده می‌شوند.
- صفحه اصلی و دسته‌بندی، حتی با عنوان و کارت قیمت، محصول تشخیص داده نمی‌شوند.

## تست

`npm run test:etkala`، با داده ثابت مبتنی بر DOM مشاهده‌شده و شبکه مسدود.
تست قبل از اصلاح با عدم تشخیص شکست خورد؛ بعد از اصلاح عنوان، قیمت، تصویر، تغییر واحد ریال، قیمت نامعلوم و کنترل‌های غیرمحصول موفق شدند.
`node test/etkala-product.test.mjs --without-fix` مسیر استخراج قبلی را بدون تغییر فایل اصلی بازسازی می‌کند تا اعتبار تست کنترل شود.
نسخه سالم تاریخی مشخصی نداریم، بنابراین commit معرفی‌کننده با bisect تعیین نشده است.

بازتست نهایی افزونه نصب‌شده با Reload و رفرش همین صفحه لازم است؛ موفقیت تست ثابت به معنی تأیید همه محصولات ات‌کالا نیست.
