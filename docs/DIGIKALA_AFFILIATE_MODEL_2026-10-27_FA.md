# بررسی لینک افیلیو کیبورد هیسکا H-MK25

محصول گزارش‌شده `dkp-22109767` است. بررسی روی Windows، شاخهٔ محلی مانیتورینگ و کد مبتنی بر `c894ada` انجام شد؛ تغییرات قبلی ثبت‌نشده حفظ شدند. کامیت معرفی‌کننده جدا نشده است.

## شاهد پاسخ واقعی API

در ۲۰۲۶/۱۰/۲۷، درخواست‌های API اصلی پیکو برای نام کامل «کیبورد و ماوس بی‌سیم هیسکا مدل H-MK25»، عبارت نرمال‌شده و پیشوند شش‌کلمه‌ای، HTTP 200 و صفر نتیجه داشتند. پیشوند سه‌کلمه‌ای «کیبورد و ماوس» ۲۰ محصول متفاوت برگرداند و این DKP در آن‌ها نبود. درخواست `H-MK25` یک نتیجهٔ دیجی‌کالا با همین DKP و لینک `publisher.affilio.ir` و قیمت ۴٬۴۹۹٬۰۰۰ تومان برگرداند. هیچ امضا یا توکنی در این سند ثبت نشده است.

مشکل از مسیر localhost نبود؛ این درخواست‌ها مستقیماً به `api.piqoo.ir` ارسال شدند. اصلاح پیشینِ پیشوند کوتاه برای این داده کافی نبود. همچنین وجود محصول از فروشگاه دیگر نباید مانع دریافت لینک محصول فعلی دیجی‌کالا شود.

## اصلاح

- بعد از پاسخ موفق جست‌وجوهای اولیه، اگر نتیجه‌ای نیست یا لینک DKP صفحه هنوز وجود ندارد، حداکثر یک جست‌وجوی جایگزین انجام می‌شود: مدل حرفی/عددی مانند H-MK25، یا در نبود چنین مدلی، پیشوند سه‌کلمه‌ای.
- در خطا یا محدودیت سرویس، درخواست اضافه ایجاد نمی‌شود.
- لینک اصلی دریافتی برای همان DKP عیناً با قیمت تأییدشده ترکیب می‌شود.
- کد قدیمی استخراج پیشوند امضاشده و تغییر مقصد آن حذف شد؛ امضای یک محصول یا فروشگاه، لینک معتبر محصول دیگری را ثابت نمی‌کند. اگر لینک همان محصول دریافت نشود، نتیجهٔ مستقیم حفظ می‌شود.
- کلید کش V21 است تا لینک مستقیم یا ساخته‌شدهٔ قبلی از کش نتایج خوانده نشود. سابقهٔ کاربر پاک نمی‌شود.

## تست و استفاده

تست `test/digikala-affiliate-model.test.mjs` پیش از اصلاح با نبود درخواست مدل شکست خورد و سپس پاس شد. داده و شبکه ثابت‌اند؛ امضا ساختگی است. حالت جست‌وجوی خالی، نتایج فروشگاه دیگر، تطبیق دقیق DKP، قیمت تأییدشده و عدم استفاده از امضای قبلی پوشش داده شده است. تست قبلی ویتامین D3 نیز حفظ شد.

دستور تست: `npm run test:digikala-all-sources`. ساخت: `npm run build:dev`. برای استفاده، افزونهٔ نصب‌شده از `dist/dev` باید Reload و صفحهٔ محصول Refresh شود. نسخهٔ نصب‌شدهٔ کاربر پس از این تغییر هنوز به‌طور خودکار تأیید نشده است. مسئلهٔ جداگانهٔ نمایش صفر محصول، از این تستِ لینک به‌تنهایی نتیجه‌گیری نمی‌شود.
